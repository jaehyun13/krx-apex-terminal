# KRX::APEX Terminal

국내·미국 증시를 한 화면에서 보는 데스크톱 터미널입니다. 시세, 차트, 호가, 수급, 공시, 거시 지표, 포트폴리오를 제공하며 Windows용 단일 실행 파일(`KRX-APEX.exe`)로 배포합니다.

![icon](public/icon.svg)

## 설치와 실행

1. [Releases](../../releases/latest)에서 `KRX-APEX.exe`를 내려받습니다.
2. 더블클릭하면 터미널 창이 열립니다. 설치 과정은 없습니다.
3. 창을 모두 닫으면 프로그램이 몇 초 뒤 스스로 종료됩니다.

서명되지 않은 파일이라 처음 실행할 때 Windows가 경고를 띄울 수 있습니다. "추가 정보 → 실행"을 누르면 됩니다.

터미널 창은 Microsoft Edge의 앱 창으로 열리고, Edge가 없으면 기본 브라우저에서 열립니다.

## 화면

| 탭 | 단축키 | 내용 |
|---|---|---|
| 마켓 종합 | F2 | 국내/미국 시장 전환. 지수 카드, 업종 매트릭스(미국은 시총 상위 종목), 순위, 수급, 프로그램 매매, 뉴스·공시 속보 |
| 종목 심층 | F3 | 차트(휠로 확대·축소, 끌어서 이동, 이동평균선), 미국 종목은 TradingView 차트 전환, 호가창, 체결 틱, 주요 지표, 연간 재무, 투자자별 순매수, 종목 뉴스·공시 |
| 거시경제 | F4 | 환율, 국채·국내·기준금리, 원자재, 해운 운임, 해외 지수, 항목별 추이 차트 |
| 맵 & 스크리너 | F6 | 시가총액 상위 종목의 업종별 트리맵(크기 = 시가총액, 색 = 등락률)과 조건 검색 표. 국내·미국 전환 |
| 포트폴리오 | F8 | 직접 입력한 보유 종목 또는 토스증권 계좌 연동. 미국 종목은 환율로 원화 환산 |

그 밖에 F1 도움말, F9 설정, `/` 명령창 포커스를 씁니다.

### 명령창

상단 `CMD>`에 입력하고 Enter를 누릅니다.

- 종목: `005930`, `삼성전자`, `AAPL`, `테슬라`
- 지수: `KOSPI`, `KOSDAQ`, `NASDAQ`, `DOW`, `SPX`
- 차트 기간: `1D`, `1M`, `3M`, `1Y`, `3Y`
- 화면 이동: `MKT`, `MACRO`, `MAP`, `PORT`, `KEYS`, `HELP`

### 속보 알림

새 뉴스나 공시가 들어오면 화면 오른쪽 아래에 알림창이 뜹니다. 창이 가려져 있으면 Windows 알림으로도 띄웁니다. 상단의 `속보 알림 ON/OFF` 버튼으로 켜고 끕니다. 30초 간격으로 확인하므로 그만큼 늦게 뜰 수 있습니다.

## API 키

키가 없어도 시세·차트·뉴스·거시·포트폴리오 직접 입력은 모두 동작합니다. 키를 넣으면 아래 기능이 추가됩니다. 설정 창(F9)에서 입력하며, 저장할 때 연결을 확인해 결과를 보여줍니다.

| 키 | 추가되는 기능 | 발급 |
|---|---|---|
| DART 인증키 | 공식 공시(종목별), 시장 전체 공시 속보 | [opendart.fss.or.kr](https://opendart.fss.or.kr) (무료) |
| 토스증권 CLIENT ID / SECRET | 호가, 체결 틱, 계좌 보유 종목(국내·미국) | 토스증권 설정 > Open API |
| 한국투자증권 APP KEY / SECRET | 국내 10단계 호가, 체결 틱·체결강도 | [apiportal.koreainvestment.com](https://apiportal.koreainvestment.com) |

토스증권은 같은 메뉴의 **허용 IP 관리**에 이 PC의 IP를 등록해야 합니다. 등록하지 않으면 호출이 차단됩니다.

모든 연동은 조회 전용이며 주문 기능은 없습니다.

키는 `%APPDATA%\KRX-APEX\settings.json`에만 저장되고, 화면에는 끝 4자리만 표시됩니다. 해당 기관 서버 외에는 전송하지 않습니다.

## 프로그램 비밀번호

설정 창(F9) 맨 아래에서 비밀번호를 설정하면 프로그램을 켤 때마다 잠금 화면이 뜹니다. "지금 잠그기"로 바로 잠글 수도 있습니다.

- 비밀번호 원문은 저장하지 않고 해시만 저장합니다.
- 잊어버리면 복구할 수 없습니다. `%APPDATA%\KRX-APEX\settings.json`을 지워야 하며, 이때 저장된 API 키도 함께 지워집니다.
- 화면과 API를 잠그는 기능입니다. 설정 파일 안의 API 키를 암호화하지는 않습니다.

## 데이터 출처와 한계

- 기본 시세·뉴스·수급은 네이버페이 증권, 해외 지수·미국 분봉 일부는 Yahoo Finance의 비공식 엔드포인트를 씁니다. 예고 없이 막히거나 형식이 바뀔 수 있습니다.
- 시세는 지연될 수 있고, 화면은 20초 간격(종목 화면의 호가·체결은 4초)으로 갱신합니다.
- 미국 주식은 투자자별 수급과 공시를 제공하지 않습니다. 미국 시장은 개인·외국인·기관의 일별 순매수를 집계해 공시하지 않기 때문입니다. 호가와 체결 틱은 토스증권 키가 있어야 나옵니다.
- TradingView 차트 위젯은 미국 종목에서만 열립니다. 국내(KRX) 종목은 위젯이 제공하지 않아 기본 차트로 표시합니다.
- 맵과 스크리너는 시가총액 상위 종목만 다룹니다(미국 400종목, 국내 약 260종목). 재무 지표(PER 등) 조건은 없습니다.
- 이 프로그램은 투자 권유가 아니며, 표시되는 정보의 정확성을 보장하지 않습니다.

## 개발

Node.js 22 이상이 필요합니다. 실행에는 외부 패키지가 필요 없고, exe 빌드에만 개발 의존성을 씁니다.

```bash
npm install
```

```bash
npm start
```

`http://localhost:3000`에서 열립니다. 이 PC에서만 접속할 수 있습니다.

### exe 빌드

```bash
npm run build
```

`dist/KRX-APEX.exe`가 만들어집니다. Windows가 아닌 OS에서도 빌드할 수 있습니다.

`main`에 푸시하면 GitHub Actions가 Windows에서 exe를 빌드하고, 실제로 실행해 응답을 확인한 뒤 새 릴리스로 올립니다.

### 구조

| 파일 | 역할 |
|---|---|
| `server.js` | HTTP 서버, API 라우팅과 캐시, 비밀번호 잠금, 창 연결 추적 |
| `data.js` | 네이버·Yahoo에서 데이터를 받아 정규화 (국내·미국) |
| `keys.js` | 설정 저장소, DART·토스증권·한국투자증권 연동 |
| `public/` | 화면 (`index.html`, `app.js`, `chart.js`, `style.css`), 차트 엔진 `lwc.js`(TradingView Lightweight Charts, Apache-2.0) |
| `build.js` | exe 빌드: 코드 묶기, 아이콘 삽입, 콘솔 창 숨김 |
| `assets/icon.ico` | exe 아이콘 |
