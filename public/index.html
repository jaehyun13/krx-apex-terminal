    TAPE
    key설정 · API 키 · 비밀번호

    키는 이 PC의 설정 파일에만 저장되고, 해당 기관 서버 외에는 전송되지 않습니다. 비워 두면 기존 값을 유지합니다.

    DART 전자공시

    공식 공시 목록(종목별·시장 전체). 발급: opendart.fss.or.kr → 인증키 신청 (무료)

    토스증권 Open API

    호가, 체결 틱, 내 계좌 보유 종목 (조회 전용, 주문 없음). 발급: 토스증권 설정 > Open API. 같은 메뉴의 허용 IP 관리에 이 PC의 IP를 등록해야 합니다.

    한국투자증권 KIS Open API

    10단계 호가, 체결 틱·체결강도 (조회 전용). 발급: apiportal.koreainvestment.com

    프로그램 비밀번호

    설정하면 프로그램을 켤 때마다 비밀번호를 묻습니다. 잊어버리면 설정 파일을 지워야 하며, 그때 저장된 API 키도 함께 지워집니다.
